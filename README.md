# FilmCam 2.2.0 · Live AI Composition

Android 10+ ARM64, including OPPO Find X8 Pro. Install FilmCam-2.2.0-OPPO.apk over the previous cloud installer to retain private imported LUTs. Package/signing key are unchanged.

The live backend now uses pinned EfficientDet-Lite0 person/object detection and a separate MobileNetV2 scene classifier through bundled LiteRT CPU interpreters. The application no longer instantiates ML Kit native vision graphs. Models, labels, source hashes and Apache-2.0 license are bundled; no runtime Internet, Play Services, account, API key or model download is needed. No camera images are uploaded.

Small camera images are copied and camera ImageProxy objects closed before inference. Initialization precedes taking the latest frame; the queue retains only one pending image. CameraX metadata maps actual neural boxes through crop/rotation/front mirror. Missing CameraX frames or geometry automatically switches to the displayed preview; Camera2 uses PixelCopy. Tracking retains actual identities without invented detections. People/foreground objects have priority over backgrounds such as dining tables. Body framing uses person proportions rather than face-crop assumptions.

The existing AI card shows loading, scanning, tracking, retry/error states. Tap to hold/resume auto zoom; manually changing zoom wins. Long-press the card for local diagnostic/copy/retry. Automatic JPEG zoom requires fresh tracking and stable evidence. Animation no longer resets detection every tick. Native photo resolution, RAW/Pro controls, video codecs, custom LUTs and film presets remain. Scene work pauses for video/export; slow primary inference yields to the encoder while real horizon guidance remains. Physical phone movement is guided, not motorized.

Validation: 182 JVM tests pass with zero failures/errors/skips; Lint has zero errors. Actual Android model detection and actual rotated/mirrored cup-box tests pass. A real SurfaceView -> PixelCopy -> both models -> tracker/StateFlow case verifies live foreground bounds, real scene context and off/on recovery; camera-control integration verifies real CameraX zoom/manual hold/JPEG saving using deliberately injected observations. The adaptive-video regression checks actual preview inference and a validated multiple-frame MP4. These are passing focused cases across runs; the initial pixel/scene fixture checked after a completed but not necessarily fresh cold-start result and was corrected to use a continuous image producer and a consistent published StateFlow snapshot. CPU emulation took up to 16,529 ms per inference; the dataflow fixture uses test-only 60-second subject/scene lifetimes, while production keeps 1,500/4,000 ms freshness and stricter auto-zoom limits. The final dataflow case passes in 52.234 seconds, with a real 0.9921875 FOOD confidence and cup bounds. The video is a validated multi-frame 11,095 ms 720p AVC clip with the slow-inference guard active.

No physical OPPO is attached; emulator/host inference times are not phone speed/FPS/optical-quality benchmarks. Models can miss unrecognized, small or occluded subjects. Composition scores are geometric, not a Huawei proprietary aesthetic model. Camera/tele/HDR/4K60 availability depends on public phone capabilities.

Version 2.2.0 (13). Same-key debug-signed personal installer distributed at the user's request. SHA-256 sidecar included.
