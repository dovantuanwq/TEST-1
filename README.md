# FilmCam 2.1.0 · Fast AI, Scene Recognition & Auto Framing

Android 10+ ARM64, including OPPO Find X8 Pro. Install FilmCam-2.1.0-OPPO.apk over the previous cloud installer to retain imported LUTs. Package and signing key are unchanged.

AI now uses one FAST face/eye/tracking model independently of background scene and object inference. Native ML work runs on explicit bounded executors: normal priority faces and background priority scenes. Bundled model assets are uncompressed for startup. Semantic scene recognition uses the packaged Google ML Kit image-labeling model; no Internet permission or model download is required. Weak/unknown labels remain unknown. Separate timestamps prevent stale object detections being renewed by empty face results.

Auto framing is enabled with AI in ordinary JPEG Photo mode. Fresh, stable observations choose a bounded zoom within the currently open camera's native logical zoom range; one eased transition reaches the desired framing. Hold time, subject identity, an edge-safe crop check, deadband and cooldown prevent abrupt or repeated changes. Manual pinch, zoom preset, slider or lens choice holds automation. Tap the AI card to hold/resume. Pro, RAW and video keep manual zoom.

Angle advice combines recognized scenes, real device roll/pitch and a detected landscape horizon. Physical phone movement remains manual; there is no fake camera motor or automatic saved-image rotation. Native image resolution, RAW, Pro controls, film presets, imported LUTs and the existing timestamp-validated video encoder remain. Slow devices pause optional inference while recording, retaining horizon guidance; outstanding model work drains before encoder startup.

Validation: 167 JVM tests pass; Lint has zero errors. Actual bundled FAST-face and scene-model Android tests pass offline. Focused camera integration cases across runs check actual CameraX zoom from injected stable composition observations, immediate AI-card hold/manual override/resume, real JPEG export, and video export with actual preview inference and the adaptive slow-inference guard. Earlier combined runs exposed CPU-emulator priority starvation, sparse synthetic test observations, frame starvation and cold label-model startup delaying recording. Explicit native priorities, realistic streamed observations, atomic/rate-limited sensor updates, skipping unchanged overlay repaints and photo-only semantic/object scheduling address those issues. The final focused video case passes in 170.625 seconds and exports a validated 12,216 ms multi-frame 720p MP4 with the slow-inference guard active. These are passing cases across runs, not a claim that earlier combined runs were entirely green. Emulator results are not OPPO speed, optical-quality or 4K60 benchmarks. Camera/tele/HDR access depends on the phone's public capabilities. No physical Find X8 Pro is connected, and Huawei proprietary algorithms are not used.

Version 2.1.0 (12). Same-key debug-signed personal testing build distributed at the user's request. See the SHA-256 sidecar for file integrity.
